# Arquitetura do OES

Este diretório abrigará o modelo conceitual, o modelo de dados e, em fase posterior, a arquitetura tecnológica do Observatório.

## Entidades conceituais já identificadas

- Pergunta — OES-Q;
- Investigação — OES-I;
- Busca — OES-S;
- Estudo — OES-ST;
- Publicação/relatório;
- Desfecho;
- Síntese;
- Avaliação metodológica;
- Produto OES.

A separação entre **Estudo** e **Publicação** é uma decisão já consolidada.

## Princípio

A arquitetura computacional será derivada da metodologia, e não o contrário.

> Metodologia antes da automação.
