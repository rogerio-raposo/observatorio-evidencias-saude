# Produtos do OES

Este diretório será usado para especificar os produtos do Observatório.

Produtos já concebidos, mas ainda não formalizados em documentos próprios:

- Evidence Scan;
- Resposta de Evidência;
- Ficha de Evidência;
- Síntese Rápida;
- Revisão de Evidências;
- Mapa de Evidências;
- Overview/Umbrella Review;
- Monitor de Evidências;
- Alerta de Evidência.

A **Ficha de Evidência** é atualmente candidata à unidade persistente central do conhecimento do OES.

Nenhuma especificação definitiva será criada antes da consolidação dos protocolos metodológicos necessários.
