# 1. Pergunta original

> **Que evidência existe sobre o uso de chatbots baseados em inteligência artificial generativa e grandes modelos de linguagem para apoio à saúde mental de adultos?**

# 2. Justificativa para N0

A pergunta é ampla e mistura dimensões que ainda precisam ser separadas:

- arquitetura tecnológica: rule-based, retrieval-based, NLP, GenAI, LLM;
- finalidade: apoio emocional, psicoterapia digital, counseling, triagem, psicoeducação;
- população: população geral, sintomas subclínicos, depressão/ansiedade, condições graves;
- desfecho: sintomas, engajamento, experiência, segurança, danos;
- contexto: ferramentas purpose-built versus chatbots gerais.

Portanto, uma resposta focal N1 imediata produziria risco de combinar intervenções e perguntas não equivalentes.

# 3. Objetivo exploratório

Mapear:

1. terminologia usada;
2. tipos de síntese disponíveis;
3. maturidade do campo;
4. áreas já sintetizadas;
5. controvérsias e riscos;
6. lacunas aparentes;
7. perguntas candidatas;
8. rota metodológica proporcional para continuidade.

# 4. Escopo inicial

População/contexto: adultos ou populações gerais com relevância para saúde mental.

Conceito: chatbots/conversational agents baseados em GenAI/LLMs usados para apoio, counseling, intervenção ou interação relacionada à saúde mental.

Exclusões conceituais iniciais:

- aplicações de LLM exclusivamente administrativas;
- classificação diagnóstica sem componente conversacional de apoio;
- chatbots puramente rule-based quando não contribuírem para entender a transição tecnológica;
- robôs físicos/embodied agents sem componente comparável.

# 5. Estratégia de busca exploratória

Fontes principais:

- PubMed/MEDLINE;
- PubMed Central quando útil para texto completo;
- buscas direcionadas a revisões recentes em periódicos de saúde digital.

Conceitos:

- generative AI;
- large language model / LLM;
- chatbot / conversational agent;
- mental health / psychiatry;
- systematic review / meta-analysis / scoping review;
- safety / harms / user experience.

Data de corte:

> **2026-10-05**

# 6. Princípios do scan

- busca estruturada e exploratória;
- não exaustiva;
- preferência por sínteses recentes;
- estudos primários apenas quando necessários para caracterizar lacuna/controvérsia;
- nenhuma meta-análise nova;
- nenhuma certainty formal OES;
- nenhuma conclusão clínica focal.

# 7. Critérios para maturidade

Categorias possíveis conforme Documento 86:

- well_synthesized;
- partially_synthesized;
- fragmented;
- emerging;
- saturated;
- insufficient.

Critérios considerados:

- existência de sínteses recentes;
- especificidade para GenAI/LLM;
- separação entre eficácia, segurança e UX;
- estabilidade terminológica;
- consistência entre populações/intervenções;
- velocidade de evolução do campo.

# 8. Gatilhos de rerroteamento

Rerrotear se:

- houver síntese específica suficiente para pergunta focal;
- eficácia e segurança exigirem perguntas distintas;
- chatbots tradicionais e GenAI não puderem ser combinados;
- campo exigir produto persistente devido rápida evolução;
- controvérsia material impedir N1 simples.
